# Nexarl Forge 白皮书

## 摘要

Nexarl Forge 是一个本地优先的人机协作开发工作空间，为 Codex 与 Claude Code 提供共享、可审批的记忆、项目上下文、设计治理、UI Skills 和 Loop 工程工作流，同时让开发者数据留在自己的 Mac 上。

## 要解决的问题

AI Coding 会反复重新发现项目决策、个人工作偏好和发布约束；未经审核的自动记忆还可能沉淀敏感或错误内容。Nexarl Forge 通过明确的项目边界和人工审批同时解决这两类问题。

## 系统架构

安装器把不可变的版本化运行时放入用户的 Application Support 目录，并提供稳定 CLI。仅监听本机回环地址的服务提供管理后台。Codex 与 Claude Code 共用用户级 hooks；控制平面根据当前工作目录选择个人上下文和最深层的已注册项目上下文。

已注册工作目录可以产生项目候选；未注册目录只能产生个人候选。正式个人长期/短期记忆和项目长期记忆均须经过审批后生效。

## 协作治理

管理后台覆盖当前记忆、项目管理、设计偏好、UI 设计审批、UI Skills、Loop 说明、记忆策略，以及迁移、修复、回滚和卸载。人工审批是长期事实的最终来源，同时不妨碍 AI 持续协作。

## 隐私与安全

服务仅绑定回环地址，不依赖第三方运行时包，保留无关 hooks，并为受管变更创建带时间戳的备份。公开发布前会检查个人路径、凭据和记忆文件，阻止其进入发行树。

## 路线图

未来版本将在保持本地优先、审批门禁和升级兼容的前提下，继续加入更多 AI Coding 人机协作能力。
